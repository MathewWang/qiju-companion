# 六位角色动作图集

使用内置 image_gen，以各自原立绘为参考生成透明 RGBA 图集。原图保留，新增资源路径如下：

- `public/characters/qinghe-motion-v1.png`
- `public/characters/xinglan-motion-v1.png`
- `public/characters/tangli-motion-v1.png`
- `public/characters/yuexia-motion-v1.png`
- `public/characters/yanzhou-motion-v1.png`
- `public/characters/jingchuan-motion-v1.png`

统一采用四列三行：第一行待机眨眼、第二行招手、第三行坐下，站起反向播放第三行。所有可选角色通过 shared/characters.json 的 motion 配置接入 AnimatedCompanion。图鉴可进入各自的动作预览，桌面也沿用消息提示、空闲休息和站起逻辑。缩略图及加载错误回退仍使用立绘。

这是十二格逐帧原型，生成帧间的姿态、面部、服装细节仍有变化，不能等同于精修骨骼动画。未来新增角色必须一并制作动作图集；见根目录 AGENTS.md。测试检查每个可选形象的图集存在、透明通道与画布比例，不能替代视觉检查。
