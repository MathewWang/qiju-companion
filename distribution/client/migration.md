# 从 qiju-companion 迁移

旧综合仓库仍保留，阿里云服务不需要变更。新客户端仓库为 `MathewWang/zhijiao-client`。请使用 Node.js 24+。

1. 正常退出旧桌面，检查并停止独立无头 Client 或手动启动的本机服务，确认没有模型调用进行中。
2. 将旧项目 `.data` 备份到私有位置。不要上传备份。
3. 克隆新客户端仓库，执行 `npm run desktop:setup`。
4. 第一次启动前，将旧项目 `.data/registration-v2` 和 `.data/client` 复制到新项目对应目录。只复制自己的数据；不要覆盖新项目已有的角色。若配置了 `COMPANION_DATA_DIR` 或 `CLIENT_DATA_DIR`，先确认实际目录并在新启动环境中保持相同设置。
5. 启动新项目 `npm run desktop`，核对角色、设备 ID、历史和好友保留，原云端地址会自动复用，不重新注册。
6. 迁移成功后只运行新项目。保留旧项目作为本地备份，不要同时启动两个相同身份的客户端。

本机持久化结构保持不变，没有重置或删除数据库的迁移步骤。源码中的 `server/` 已更名为 `runtime/`，这是仅运行在用户电脑上的本地服务；它不包含云端 Relay。UI 定制提交在新仓库进行。
